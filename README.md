# Steam 浏览

让麦麦搜索游戏、查看价格折扣、浏览特惠和玩家评价，查询公开玩家资料、游戏库及近两周游玩。

## 使用

1. 将插件放入 MaiBot 的 `plugins/steam_browser_plugin` 目录并加载。
2. 在 WebUI → 插件管理 → Steam 浏览 → 配置中设置商店地区、语言和可选代理，保存。商店和评价查询无需密钥。
3. 对麦麦说：“看看博德之门 3 现在多少钱”“找几款打折的合作游戏”或“看看这款游戏的中文差评”。

查询玩家时，先在配置中填写 [Steam API 密钥](https://steamcommunity.com/dev/apikey)。可设置默认玩家，也可在聊天中提供 SteamID64 或玩家主页链接，例如：“看看这个玩家最近玩了什么”。只能查询玩家公开的数据。
